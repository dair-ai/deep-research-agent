System Architecture
User Query

Orchestrator Agent

Coordinates the sequential pipeline, routing queries through each specialized subagent and managing data flow between stages.

Planner Agent
STEP 1

Analyzes topic and creates 5-10 optimized search queries with date ranges.

Tools

Planning only (no tools)

Web Search Agent
STEP 2

Executes search plan with date filters, gathers 10-15 sources using Exa.

Tools

exa.search exa.get_contents exa.find_similar
Analysis Agent
STEP 3

Identifies themes, extracts key findings, and structures insights from gathered sources.

Tools

Text processing only (no tools)

Report Writer Agent
STEP 4

Transforms analyzed findings into a comprehensive, well-structured markdown report.

Tools

Text generation only (no tools)

Data Flow Between Stages
1
Planner

Analyze Topic & Create Search Plan

Analyzes the research topic with current date/time, determines appropriate date ranges, and generates 5-10 optimized search queries.

Output Data
{
  date_range: {
    start: "2024-06-01",
    end: "2024-12-17"
  },
  queries: [5-10]
}
2
WebSearch

Execute Search Plan

Runs all planned queries with date filters (start_published_date, end_published_date), retrieves full content, and finds similar articles.

Output Data
{
  sources: [
    { title, url, author,
      content, date }
  ] // 10-15 items
}
3
Analysis

Analyze & Structure

Identifies major themes, extracts key findings with citations, notes contradictions between sources, and assesses overall quality and gaps.

Output Data
{
  themes: [...],
  findings: [...],
  statistics: [...],
  gaps: [...]
}
4
ReportWriter

Generate Report

Transforms structured analysis into a polished markdown report with table of contents, executive summary, themed sections, and properly cited sources.

Output Data
## Table of Contents
## Executive Summary
## Key Findings
## Analysis
## Sources
